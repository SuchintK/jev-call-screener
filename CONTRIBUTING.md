# Contributing

Thank you for contributing to JEV Call Screener.

1. Fork the repository and create a focused branch.
2. Do not commit credentials, caller transcripts, or other personal data.
3. Add tests for behavior changes.
4. Run `go test ./...`, `go vet ./...`, and `go build ./...`.
5. Open a pull request describing the change and its security/privacy impact.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
